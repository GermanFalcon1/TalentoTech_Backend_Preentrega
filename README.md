# La Empanadería

Sitio web de una empanadería argentina. Es la pre-entrega del proyecto de Frontend (Talento Tech): muestra el menú de empanadas, reseñas de clientes y un formulario de contacto.

## Contenido

- `index.html`: inicio, menú de empanadas (Flexbox) y reseñas (Grid).
- `pages/sobreNosotros.html`: historia del emprendimiento.
- `pages/contacto.html`: datos de contacto y formulario (responsivo con media queries).
- `css/styles.css`: estilos, Google Fonts (Bricolage Grotesque y Figtree) y fondo con degradado.
- `js/nav.js`: menú desplegable en celulares.
- `img/`: ilustraciones de las empanadas en SVG.

## Formulario de contacto

Envía nombre, correo y mensaje con [Formspree](https://formspree.io). Para activarlo, creá un formulario en Formspree y reemplazá `TU_ID` en `pages/contacto.html` por tu código (`https://formspree.io/f/TU_ID`).

## Publicación

Subí la carpeta a un repositorio público de GitHub y activá GitHub Pages en *Settings > Pages* (rama `main`, carpeta `/root`).
